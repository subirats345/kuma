## Profile

Kuma turns a small Markdown file into a clean native macOS PDF. The layout is intentionally quiet: generous margins, compact headings, comfortable line height, and links highlighted with a soft red accent.

## Notes

- Write the source in plain Markdown.
- Use level one and level two headings for structure.
- Keep bullets short when you want the PDF to feel calm and editorial.
- Emails and URLs are colored automatically.

## Short Bio

This page is only a minimal sample, but it is enough to verify the full path: Markdown input, native CoreText layout, Quartz PDF output, and a command-line workflow that can be reused from any folder.
